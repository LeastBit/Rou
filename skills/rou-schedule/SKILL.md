# Rou 日程 · Agent 操作手册

Rou 是一个常驻桌面的日程浮窗（Windows），提供命令行与文件投递两种接口。
所有操作都在本地完成，**不联网**。Agent 通过下面两种方式之一读写任务。

## 0. 定位可执行文件

按顺序检查，命中即用：

```
D:\Projects\Rou\dist\Rou.exe
%LOCALAPPDATA%\Rou\Rou.exe
%APPDATA%\Rou\Rou.exe
```

也可让用户告知路径。下文用 `$ROU` 代指该路径。

数据目录固定为 `%APPDATA%\Rou`（即 `C:\Users\<用户>\AppData\Roaming\Rou`）。

## 1. 两种写入方式

### 方式 A：命令行（首选，有返回值）

```bash
"$ROU" --add "明天下午3点 产品评审 #工作 !!"
```

返回单行 JSON，`ok:true` 且 `added` 数组里能看到解析后的 `title` / `due` / `priority` / `tags`：

```json
{"ok":true,"added":[{"id":"bc8f645c9a4c","title":"产品评审","due":"2026-10-23 15:00","hasTime":true,"priority":2,"tags":["工作"],"repeat":null}]}
```

要点：
- **始终检查返回的 `due`**：自然语言解析有歧义时（例如"下周一"跨年、只写"9点"已过点），要以返回值为准向用户复述。
- 一次加多条：用 `；` 分隔，或调多次 `--add`。
- `--add --agent "..."` 会把来源标记为 `agent`，便于回溯。

### 方式 B：投递 JSON（命令执行被沙箱拦截时用）

把文件写到 `%APPDATA%\Rou\inbox\` 下，组件会在 1 秒内摄取，处理后移到 `inbox\_done\`：

```json
{
  "tasks": [
    { "title": "提交报销单", "due": "2026-10-24 11:00", "priority": 3, "tags": ["财务"] },
    { "raw": "下周一 09:30 部门周会 #工作" }
  ]
}
```

也接受 `["明天9点 交报告", "买咖啡豆"]`、`{"raw": [...]}`、`{"text": "..."}`。

字段：`title`、`due`（`yyyy-MM-dd HH:mm` 或 `yyyy-MM-dd`，缺时刻=全天）、`priority`（0–3 或 高/中/低）、`tags`、`repeat`（`daily` / `weekdays` / `weekly:2` / `monthly:1`）、`notes`、`raw`（自然语言）。

## 2. 读取

```bash
"$ROU" --list        # 未完成，含 id/due/priority/tags/source
"$ROU" --archive 20  # 最近归档
```

只读查询不想启动进程时，直接读文件即可（UTF-8 JSON，字段 camelCase）：

- `%APPDATA%\Rou\tasks.json` — 未完成
- `%APPDATA%\Rou\archive.json` — 已归档（含 `completedAt`）

## 3. 完成 / 归档

```bash
"$ROU" --done 3f2a1b       # 按 id 前缀
"$ROU" --done 2            # 或按当前排序序号（从 1 开始）
```

完成即归档，重复任务会自动生成下一次实例。

## 4. 自然语言写法（写给 `--add` 用的）

| 意图 | 写法 |
|---|---|
| 日期 | `今天` `明天` `后天` `下周一` `周五` `3天后` `10月25日` `2026-11-03` `月底` |
| 时刻 | `9:30` `15点` `下午3点` `晚8点半` `中午12点` `明晚8点` `9:00-10:30` |
| 优先级 | `!` 低 `!!` 中 `!!!` 高，或 `重要` `紧急` |
| 标签 | `#工作` `#财务` |
| 重复 | `每天` `工作日` `每周三` `每月1日` |
| 全天 | `明天 全天 搬家` |

解析规则里的两个默认值，复述时注意：
- 只写小时且 ≤6 时按**下午**理解（"3点" = 15:00）；
- 只说时刻且**已过点**则顺延到**明天**。

## 5. 建议的对话模式

- 用户说"提醒我明天开会"但没说时间 → 追问时间，或补 `明天 09:00` 并说明假设。
- 添加后回一句确认：**标题 + 时间 + 标签**，例如"已加入：产品评审 · 明天 15:00 · #工作"。
- 用户问"今天还有什么" → `--list` 后按 `due` 分组复述，逾期项优先。
- 批量导入（会议纪要、邮件待办）→ 优先用 inbox JSON，一次写入多条。

## 6. 注意事项

- 路径含空格时务必加引号；PowerShell 里用 `& "$ROU" --add "..."`。
- 直接改 `tasks.json` **不安全**：组件运行时会持有内存副本并可能覆盖，请一律走 `--add` / `--done` / inbox。
- 命令行是 GUI 子系统程序，但已接管 stdout，可直接捕获输出；若返回乱码，改用 inbox 方式。
- 时间是本机本地时间，不做时区换算。
- 归档上限 3000 条，超出自动丢弃最旧记录。
- 用户若开启"桌面层模式"，浮窗会沉到其它窗口之下，用 `Ctrl+Alt+P`（或实际绑定的快捷键，见设置面板）唤出。
